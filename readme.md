# Risk Models: Monte Carlo Option Pricing

This repository documents my transition into data-driven financial modeling, starting from first principles.

The notebook here simulates a European call option using Monte Carlo simulation. It's built from scratch using Python and focuses on clarity, interpretability, and control.

## Why this matters

I come from a shift-based, industrial background—where systems had to be monitored, failures had to be predictable, and decisions had to be justifiable. These values translate directly into risk modeling.

This repo is part of my reskilling path (CQF + CFA L1) toward structured finance and FinTech analytics. I don't claim to be a finished product—I just make sure I learn out loud, clean, and verifiable.
